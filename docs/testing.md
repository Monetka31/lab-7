## Покрытие

- Для каждого из трёх ресурсов выполнены все пять операций (список, один объект, создание, изменение через PUT и PATCH, удаление).
- Ошибки: 400 (не JSON), 404 (записи нет, старый адрес `/api/tasks`), 405 (нет такого метода), 422 (не прошла проверка), 409 (место занято; нельзя удалить запись, на которую есть ссылки).
- Фильтры: `?status=`, `?workspace_id=`, `?department=`; вложенные адреса `/api/workspaces/{id}/bookings` и `/api/employees/{id}/bookings`.
